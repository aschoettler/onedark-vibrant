# OneDark Vibrant

A high-contrast dark theme based on Atom One Dark, with vibrant syntax colors.

For Nix files, pair it with [Helix Nix Highlighting](https://marketplace.visualstudio.com/items?itemName=onedark-vibrant-theme-dev.helix-nix-vscode),
which colors Nix the way the Helix editor does. The theme includes colors for
its tokens.

## Helix

The same theme is available for the Helix editor, with Home Manager modules to
install it. See [helix-themes/README.md](helix-themes/README.md).
